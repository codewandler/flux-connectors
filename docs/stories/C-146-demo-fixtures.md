# Recorded fixtures so the explorer can demonstrate an operation

## Goal

Give each operation a canned response, so running one in the explorer shows something real rather
than an empty shell.

## Acceptance

- [ ] A fixture format for a recorded response, and fixtures for a **selected** set of operations —
      not all 97. Pick the ones that demonstrate something: a nested body, a query string, an error
      envelope, a paginated read.
- [ ] A **demo** `Transport` implementation from [C-145](C-145-dry-run-transport.md)'s seam, returning
      the recorded response for an operation and refusing loudly for one with no fixture. A silent
      empty response would read as "the vendor returned nothing", which is a different fact.
- [ ] **No credential value in any fixture**, and no realistic-looking placeholder. A token-shaped
      string has tripped GitHub's push protection and blocked a release in this repo before.
- [ ] **No personal data.** Vendor documentation examples carry names, emails and phone numbers.
      Scrub them — a public catalogue is not the place for a sample customer record, even a fictional
      one that looks real.
- [ ] **Failing-first test:** `a_demo_response_contains_no_credential_and_no_personal_data`, run over
      every fixture with a sentinel set.
- [ ] Fixtures are **committed and offline**. Nothing fetches them, and no fixture is generated by
      calling a vendor — the standing rule.
- [ ] The gate is green; the build stays a fixed point.

## Notes

- **Depends on [C-145](C-145-dry-run-transport.md)** for the transport seam.
- **The honesty requirement is the whole story.** A demo that shows a plausible-looking response the
  vendor would never send teaches the reader something false about the connector. Where a fixture is
  derived from vendor documentation rather than a real call, say so **in the fixture**, so nobody
  later mistakes it for evidence the operation works.
- This does **not** prove an operation works against the live vendor. That is C-15's live-call story,
  and nothing here should be worded as if it substitutes for it.
- Prefer fewer, better fixtures. Ten operations that demonstrate the interesting shapes beat 97 that
  each return `{}`.
