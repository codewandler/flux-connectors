# flux-connectors — backlog & status board

The single screen for **"what to work on next and where we are."** One file per story lives in this
directory (`<ID>-<slug>.md`; frontmatter carries `status`/`priority`/`pillar`/`epic`, plus optional
query-only `areas`). The lists below are **generated** from that frontmatter by `/track:board` — edit
the stories, not the generated region. New work? Copy [`_TEMPLATE.md`](_TEMPLATE.md) or run
`/track:story`. For the bigger picture see the [roadmap](../roadmap.md); for the working loop see
[AGENTS.md](../../AGENTS.md) → **"Start here"**.

## Status

Repository just scaffolded; nothing implemented yet. Every story belongs to the single
**connectors-v1** epic. Ordering rationale: scaffold first (`C-1`), then design the `$auth` seam
(`C-16`) because it must ship in a `../flux` release before milestone 1 can go green — it has the
longest lead time and blocks the finish, not the start. The spec crate (`C-2`–`C-7`) and codegen
crate (`C-8`–`C-12`) follow, then the CLI (`C-13`–`C-15`).

Gate: `cargo build --workspace && cargo test --workspace && cargo clippy --workspace --all-targets --
-D warnings && cargo fmt --all --check`.
